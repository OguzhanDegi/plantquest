# User Stories

## MVP 0.1

### US-001: Pflanze erfassen

Als Nutzer möchte ich eine neue Pflanze erfassen können, damit ich Informationen zu einer Pflanze in meiner persönlichen Sammlung speichern kann.

#### Akzeptanzkriterien

* Der Nutzer kann ein Foto der Pflanze aufnehmen oder auswählen.
* Der Nutzer kann den Namen der Pflanze eingeben.
* Der Nutzer kann eine kurze Beschreibung eingeben.
* Der Nutzer kann die Pflanze speichern.

---

### US-002: Pflanzenseite anzeigen

Als Nutzer möchte ich eine übersichtliche Pflanzenseite sehen, damit ich Informationen zu einer Pflanze einfach lesen und lernen kann.

#### Akzeptanzkriterien

* Die Pflanzenseite zeigt das Pflanzenfoto.
* Die Pflanzenseite zeigt den Pflanzennamen.
* Die Pflanzenseite zeigt die Beschreibung.
* Die Informationen werden übersichtlich dargestellt.

---

### US-003: Pflanze zur Sammlung hinzufügen

Als Nutzer möchte ich eine Pflanze dauerhaft speichern können, damit ich sie später wiederfinden kann.

#### Akzeptanzkriterien

* Eine erfasste Pflanze kann gespeichert werden.
* Gespeicherte Pflanzen bleiben nach dem Schließen der App erhalten.
* Jede gespeicherte Pflanze besitzt mindestens ein Bild, einen Namen und eine Beschreibung.

---

### US-004: Pflanzensammlung ansehen

Als Nutzer möchte ich meine gespeicherten Pflanzen in einer Sammlung sehen, damit ich meine Entdeckungen jederzeit erneut ansehen kann.

#### Akzeptanzkriterien

* Die Sammlung zeigt alle gespeicherten Pflanzen.
* Jede Pflanze wird als Karte oder Liste dargestellt.
* Der Nutzer kann eine Pflanze auswählen.
* Nach Auswahl wird die Pflanzenseite geöffnet.
