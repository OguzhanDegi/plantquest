# User Stories

## MVP 0.1

### US-001: Pflanzenseite anzeigen

Als Nutzer möchte ich eine übersichtliche Pflanzenseite sehen, damit ich eine Pflanze besser kennenlernen und mir wichtige Informationen merken kann.

#### Akzeptanzkriterien

- Die Pflanzenseite zeigt den deutschen Namen(wissenschaftlichen Namen) der Pflanze.
- Die Pflanzenseite zeigt ein Bild der Pflanze.
- Die Pflanzenseite zeigt eine kurze Beschreibung.
- Die Pflanzenseite zeigt Besonderheiten.
- Die Pflanzenseite zeigt Informationen zur Verwendung.
- Die Pflanzenseite zeigt Informationen zur Essbarkeit.
- Die Pflanzenseite zeigt Fun Facts.

---

### US-002: Pflanze zur Sammlung hinzufügen

Als Nutzer möchte ich eine Pflanze zu meiner persönlichen Sammlung hinzufügen, damit ich gefundene Pflanzen später wiederfinden kann.

#### Akzeptanzkriterien

- Eine Pflanze kann gespeichert werden.
- Gespeicherte Pflanzen bleiben in der Sammlung erhalten.
- Eine gespeicherte Pflanze enthält mindestens Name, Bild und Beschreibung.
- Der Nutzer erhält eine Rückmeldung, wenn die Pflanze gespeichert wurde.

---

### US-003: Pflanzensammlung ansehen

Als Nutzer möchte ich meine gesammelten Pflanzen in einer Übersicht sehen, damit ich meinen Lernfortschritt und meine Entdeckungen nachvollziehen kann.

#### Akzeptanzkriterien

- Die Sammlung zeigt alle gespeicherten Pflanzen.
- Jede Pflanze wird mit Bild und Name angezeigt.
- Der Nutzer kann eine gespeicherte Pflanze öffnen.
- Die Sammlung ist übersichtlich und einfach verständlich.
