# MVP Scope

## Ziel von MVP 0.1

Das Ziel von MVP 0.1 ist die Entwicklung der ersten funktionsfähigen Version von PlantQuest.

Der Nutzer soll eine Pflanze erfassen, eine Pflanzenseite erstellen, die Pflanze speichern und seine persönliche Sammlung ansehen können.

Der Fokus liegt darauf, den grundlegenden Ablauf der App vollständig umzusetzen, bevor KI-Funktionen oder weitere Erweiterungen hinzugefügt werden.

---

## Enthaltene User Stories

### US-001: Pflanze erfassen

Der Nutzer kann:

* ein Foto einer Pflanze aufnehmen oder auswählen
* einen Pflanzennamen eingeben
* eine kurze Beschreibung eingeben
* die Pflanze speichern

### US-002: Pflanzenseite anzeigen

Der Nutzer kann:

* das Pflanzenfoto ansehen
* den Pflanzennamen ansehen
* die Beschreibung ansehen

### US-003: Pflanze speichern

Der Nutzer kann:

* eine Pflanze dauerhaft speichern
* gespeicherte Pflanzen später erneut öffnen

### US-004: Pflanzensammlung ansehen

Der Nutzer kann:

* alle gespeicherten Pflanzen sehen
* eine Pflanze auswählen
* zur Pflanzenseite navigieren

---

## Nicht Bestandteil von MVP 0.1

Folgende Funktionen werden bewusst auf spätere Versionen verschoben:

* automatische Pflanzenerkennung durch KI
* automatische Erstellung von Pflanzeninformationen
* Fragen an eine KI stellen
* Erweiterung von Pflanzenseiten durch KI
* Quizmodus
* Lernmodus
* tägliche Challenges
* Erfolge und Badges
* Benutzerkonten
* Cloud-Synchronisierung
* Community-Funktionen
* Ranglisten

---

## Kernablauf des MVP

1. Nutzer fotografiert eine Pflanze.
2. Nutzer gibt Name und Beschreibung ein.
3. Die App erstellt eine Pflanzenseite.
4. Die Pflanze wird gespeichert.
5. Die Pflanze erscheint in der Sammlung.
6. Die Pflanzenseite kann erneut geöffnet werden.

---

## Erfolgskriterium

MVP 0.1 gilt als erfolgreich, wenn ein Nutzer eine Pflanze erfassen, speichern und später erneut aus seiner Sammlung öffnen kann.
